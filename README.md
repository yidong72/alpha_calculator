## Frequently Asked Questions

### General Questions

**Q: What is Alpha Calculator?**
A: Alpha Calculator is an iOS app that provides a powerful scientific calculator with a clean interface, supporting both basic arithmetic and advanced mathematical functions.

**Q: What devices are supported?**
A: Alpha Calculator is available for iPhone and iPad running iOS 16.0 or later, with full support for all orientations including portrait and landscape modes.

### App Features

**Q: What mathematical functions are available?**
A: The app includes a comprehensive set of functions including:
- Basic arithmetic (addition, subtraction, multiplication, division)
- Scientific functions (sin, cos, tan, log, ln)
- Advanced operators (powers, roots, factorials)
- Memory functions (MC, MR, M+, M-)
- Angle mode switching (DEG/RAD)

**Q: Does the app support offline use?**
A: Yes, all calculator functions work completely offline once the app is installed.

**Q: Does the app support Dark Mode?**
A: Yes, Alpha Calculator automatically adapts to your device's appearance settings, providing both light and dark modes.
